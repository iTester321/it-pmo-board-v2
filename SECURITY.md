# Security review (v2)

Method: STRIDE pass over a client-only app with one outbound call (FormSubmit).

| Area | Finding | Status |
|---|---|---|
| XSS | All user strings pass `escapeHtml()` before `innerHTML`; toasts use `textContent`; icons are static SVG strings. Tested with `<img onerror>` and `<script>` payloads: rendered as inert text. | OK |
| CSP | v1 had none. v2 adds a meta CSP: `default-src 'none'`, script/style allowed by SHA-256 hash only, `connect-src https://formsubmit.co`, no images/fonts, `base-uri 'none'`, `form-action 'none'`. No inline event handlers or `style=` attributes; dynamic widths use the CSSOM. Hashes are regenerated by `scripts/update-csp.py` and checked in CI. | Fixed |
| Third-party code | No CDN scripts, fonts or libraries, so no SRI is needed. | OK |
| Data egress | Task title, description and assignee are sent to formsubmit.co. Fetch now uses `credentials: "omit"` and `referrerPolicy: "no-referrer"`. | Mitigated |
| Trademark / identity | v1 used the prefix `UOB-ITPM-` (a real bank name) in task IDs and email subject, against the "no real bank trademarks" rule. Now `ITPM-` and `[IT PMO]`. | Fixed |
| Input validation | Length caps on title/description/assignee/search; select values checked against the reference lists before add. | Fixed |
| Storage | No localStorage/sessionStorage/IndexedDB/cookies. Theme choice is in memory only. | OK |
| Secrets | Endpoint holds a placeholder address; `.gitignore` covers common secret files; CI runs gitleaks. | OK |

## Residual risks

- A meta CSP cannot set `frame-ancestors`, so the page can be framed (clickjacking). GitHub Pages cannot send headers.
- FormSubmit is a third party and the endpoint (with any real email address) is visible in page source. Do not use for real bank data or commit a real address to a public repo.
- A hash-based CSP means any edit to inline CSS/JS requires running `python3 scripts/update-csp.py`.
